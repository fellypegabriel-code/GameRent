O GameRent é um projeto acadêmico que simula uma plataforma de locação digital de jogos. A proposta é permitir que os usuários visualizem um catálogo, consultem informações sobre os jogos e realizem locações de forma simples e intuitiva.

O sistema representa uma primeira versão demonstrativa.

Objetivo geral: Desenvolver uma aplicação web interativa para simular a locação digital de jogos.

Objetivos específicos:

Criar uma interface simples e responsiva.
Disponibilizar um catálogo de jogos.
Permitir cadastro e edição de usuários.
Registrar, consultar e cancelar locações.
Armazenar informações no navegador.

Foram utilizadas as seguintes tecnologias:

HTML5: estrutura das páginas.
CSS3: estilização e identidade visual.
JavaScript: funcionalidades e interações.
Bootstrap: componentes e responsividade.
RAWG API: consulta de informações sobre jogos.
LocalStorage: armazenamento local dos dados.


O GameRent possui as seguintes telas e funcionalidades:

Login e cadastro: acesso e criação de usuários.
Catálogo: visualização, pesquisa e filtragem de jogos.
Detalhes do jogo: apresentação de informações do jogo selecionado.
Meus aluguéis: consulta e gerenciamento das locações.
Perfil: visualização e atualização dos dados do usuário.

Armazenamento com LocalStorage

O LocalStorage é utilizado para armazenar informações diretamente no navegador, permitindo manter os dados do usuário e das locações mesmo após atualizar ou fechar a página.
Por ser um projeto demonstrativo, esse armazenamento não substitui um banco de dados ou um sistema seguro de autenticação.

O desenvolvimento do GameRent permitiu aplicar conhecimentos de desenvolvimento web, integração com API e manipulação de dados com JavaScript. O projeto apresenta uma versão inicial funcional de uma plataforma de locação digital de jogos e pode receber melhorias e novas funcionalidades futuramente.
